# Advertising ML Project

This project is a machine learning classification project based on the dataset `Advertising_data.csv`.

## Goal
The goal is to predict whether a user will purchase a product based on:
- Gender
- Age
- EstimatedSalary

## Files
- `code.ipynb` : main notebook with the machine learning workflow
- `Advertising_data.csv` : dataset used in the project

## Models
This project compares different classification models to predict the target variable `Purchased`.

## Target
- `Purchased` = 0 or 1
